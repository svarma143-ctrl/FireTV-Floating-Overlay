# Fantasy Overlay — Submission Package

**Hackathon:** Build, Ship, Shape — Amazon Developer Hackathon (Fire TV track)
**Project:** Parallel fantasy sport TV overlay

## 📝 Project Description (draft)

Live fantasy sports intelligence, natively delivered to the TV.

A floating overlay runs over live game video on Fire TV / Vega, presenting real-time game context, player stats, and AI-generated insights directly into the viewing experience. Instead of flipping to a fantasy app, the intelligence comes to the game — open the overlay, see the matchup state, drill into your players, get an AI take.

## 🧰 Tools / APIs / SDKs Used (for product feedback)

- Amazon Fire TV / Vega OS (demo platform)
- React Native TV patterns (multi-TV starter patterns)
- Amazon Bedrock (AI insight generation — AWS Builder mini-challenge eligible)

## 📦 Product Feedback

- **What worked:** Overlay architecture (phase-based) kept interactions clean; AI insight layer added clear value; game-context-first design.
- **What needs work:** Real device focus/harness validation; live AI generation latency; occlusion tuning during live plays.
- **Onboarding:** Developer setup via Amazon device tooling; no device required for logic demo (simulator path).
- **Would build again:** Yes — especially AI-native delivery layer.
