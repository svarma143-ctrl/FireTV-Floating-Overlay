# Demo Video Script — Fantasy Overlay

**Hackathon:** Build, Ship, Shape — Amazon Developer Hackathon (Fire TV track)
**Runtime target:** < 3 minutes
**Platform:** Fire TV / Vega simulator (per requirements, must show running on device or simulator)

## Shot list

1. **Cold open (0:00–0:08)** — NFL game fullscreen on Fire TV. Remote: press "Open Fantasy Overlay." Overlay animates up (slide + fade).
2. **Reveal (0:08–0:25)** — Overlay shows game zone: matchup, quarter, score. Glance beat.
3. **Interact (0:25–0:45)** — Focus Next → players zone. Select player → detail card (stat line + fantasy relevance).
4. **AI (0:45–1:10)** — Focus Next → insight zone. AI Insight card renders.
5. **Dismiss (1:10–1:30)** — Back → overlay animates down, game fullscreen.
6. **Post-game (1:30–1:50)** — Status flips to Final → auto-dismiss.
7. **Close (1:50–2:00)** — End card / fade.
